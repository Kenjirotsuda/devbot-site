Getting Started

The easiest way to get started is to join DEV TESTER and use the commands available to your Discord role.

Some commands may only be available to developers, testers, moderators, or administrators.

Moderation

Tools for managing the Discord server.

  • Warnings
  • Timeouts
  • User information
  • Moderation logs

Testing

Tools designed for testers working with the Roblox game.

  • Test status
  • Bug reporting
  • Tester utilities
  • Test notifications

Developer

Tools intended for members of the development team.

  • Development status
  • Testing controls
  • Developer utilities

Utility

General-purpose Discord commands.

  • Server information
  • User information
  • Bot status
  • Help
  • Ping

Reporting Bugs

Found something broken? Good. That's what testing is for.

When reporting a bug, include what you were doing, what command you used, what happened, and what you expected to happen.

Please don't intentionally exploit a bug in DEV BOT. Report it instead.

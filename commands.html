Commands

Everything DEV BOT can currently do.

General

/help

Displays the available DEV BOT commands.

/help

/ping

Checks the bot's response time.

/ping

/botinfo

Displays information about DEV BOT.

/botinfo

Moderation

/warn

Warns a member of the server.

/warn <user> <reason> Required permission: Moderator

/timeout

Temporarily prevents a member from communicating.

/timeout <user> <duration> <reason> Required permission: Moderator

/kick

Removes a member from the server.

/kick <user> <reason> Required permission: Moderator

/ban

Bans a member from the server.

/ban <user> <reason> Required permission: Moderator

Testing

/test

Provides testing-related functionality.

/test Required role: Tester

/bug

Creates a bug report.

/bug <description> Required role: Tester

/teststatus

Displays the current testing status.

/teststatus

Developer

/dev

Provides developer-only tools.

/dev Required role: Developer

/devstatus

Displays the current development status.

/devstatus Required role: Developer

Utility

/userinfo

Displays information about a Discord user.

/userinfo <user>

/avatar

Displays a user's Discord avatar.

/avatar <user>

/serverinfo

Displays general information about the server.

/serverinfo
